# Simple Python Chatbot

A simple chatbot implementation in Python that can handle basic conversations, tell time and date, and respond to greetings.

## Features

- Responds to greetings (hi, hello, hey)
- Tells current time and date
- Handles basic conversation
- Provides help information

## Usage

1. Make sure you have Python installed
2. Run the script:
   ```bash
   python chatbot.py
   ```
3. Interact with the chatbot through the command line
4. Type 'bye', 'goodbye', or 'exit' to end the conversation

## Example Commands

- "hello"
- "what time"
- "what date"
- "how are you"
- "help"
- "bye"

## Requirements

- Python 3.x
- No additional packages required
